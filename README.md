# Storystak Skills — retired

**This repository is archived and no longer updated** (October 2026).

These skills now ship inside every Storystak Stak. Connect your Stak to
Claude and they are already there, kept current with the Stak itself, with
nothing separate to install or update.

The copies below are the last public versions, left as they were. They
remain MIT licensed (see `LICENSE`), so you are free to read, use and fork
them, but they will not receive fixes.

| Skill | What it did |
|---|---|
| **storystak-cro** | Audits and rewrites landing pages, sites, funnels and forms. |
| **storystak-anti-slop-design** | Keeps UI from converging on the default AI look. |
| **full-output-enforcement** | Forces complete, unabridged output. |
| **stak-conventions** | How to work with a Stak connector. |
| **copy-check** | Pre-ship gate for copy: findings and a PASS/FAIL, never rewritten copy. |
| **stak-update-request** | Files a correction a reviewer can act on. |
| **stak-onboarding** | A non-technical first session with a Stak. |
| **team-onboarding** | Walks a new hire through the company's own onboarding from the Stak. |

If you installed one of these as a plugin or uploaded skill, you can
remove it: with a Stak connected, the Stak serves the current version.

Built by [Storystak](https://storystak.com).
