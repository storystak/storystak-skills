## 7. Compliance — The Red List & Green List

This is the most important section for regulated industries. Skip if there are truly no restrictions, but in most industries something belongs here.

### Red List (Never Use)

| NEVER SAY | SAY INSTEAD |
|---|---|
| | |
| | |

Common categories to consider:
- **Regulated language:** legal, lawyer, attorney, contract, lawsuit, guarantee, refund (FTC/state-bar), prescribe, diagnose, cure (FDA), advice, recommendation (SEC/FINRA)
- **Superlatives:** "#1," "best," "guaranteed," "100%," "always," "never"
- **Competitor names:** Many clients can't name competitors directly
- **Sensitive promises:** money-back guarantees, results promises, health claims, income claims
- **Brand-tone violations:** specific phrases the client has ruled out internally (e.g., no "leverage," no "synergies," no "game-changer")

### Green List (Pre-Approved Phrasing)

Phrases that have been approved by legal/leadership and can be used freely. Pre-approved compliance-safe phrasing for things the client wants to say but has to say carefully.
